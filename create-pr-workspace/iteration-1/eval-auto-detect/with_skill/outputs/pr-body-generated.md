# create-pr 스킬: PR 생성 자동화

## 요약
create-pr 스킬을 통해 git 변경사항을 자동 분석하고, 프로젝트의 사용 언어(한국/영문)를 감지하여 적절한 PR 템플릿으로 PR을 생성합니다. 이 PR은 한국어 프로젝트로 감지되어 한국어 템플릿이 자동 적용되었습니다.

## 변경사항
- [ ] **신규 스킬**: create-pr 스킬 디렉토리 및 파일 구조 추가
- [ ] **템플릿**: 한국어(template-ko.md) 및 영문(template-en.md) PR 템플릿 생성
- [ ] **문서화**: 프로젝트 언어 감지 로직 및 사용 시기 설명

### 수정된 파일
- `create-pr/SKILL.md` - 스킬 정의 및 워크플로우
- `create-pr/references/template-ko.md` - 한국어 PR 템플릿
- `create-pr/references/template-en.md` - 영문 PR 템플릿
- `create-pr/evals/evals.json` - 테스트 케이스

## 테스트 계획
1. **언어 감지**: README.md에서 한글 비율 > 50% 감지 → 한국어 템플릿 선택 ✓
2. **PR 템플릿 적용**: 한국어 템플릿의 구조(요약, 변경사항, 테스트 계획, 체크리스트) 확인
3. **자동 PR 생성**: `gh pr create` 명령 실행 (인증 및 원격 브랜치 필요)
