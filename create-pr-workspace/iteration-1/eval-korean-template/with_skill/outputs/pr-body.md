# feat: 새로운 기능 추가

## 요약
PR 생성 자동화 스킬을 추가합니다. git 변경사항을 분석하고 프로젝트의 사용 언어를 자동으로 감지하여 한국어 또는 영문 템플릿을 선택해 PR을 생성합니다.

## 변경사항
- [x] **기능**: PR 생성 자동화 스킬 (create-pr) 구현
- [x] **기능**: 프로젝트 언어 자동 감지 (한국어/영문)
- [x] **기능**: 한국어 PR 템플릿 작성
- [x] **기능**: 영문 PR 템플릿 작성

### 수정된 파일
- `create-pr/SKILL.md` - 스킬 정의 및 워크플로우
- `create-pr/references/template-ko.md` - 한국어 PR 템플릿
- `create-pr/references/template-en.md` - 영문 PR 템플릿
- `create-pr/evals/evals.json` - 테스트 케이스

## 테스트 계획
1. **준비**: 한국 프로젝트와 영문 프로젝트 테스트 환경 준비
2. **수행**: 각 프로젝트에서 `create-pr` 스킬 호출
3. **예상 결과**: 프로젝트 언어에 맞는 템플릿으로 PR 생성

이 스킬은 `create-pr` 명령어로 트리거되며, 다음 상황에서 사용됩니다:
